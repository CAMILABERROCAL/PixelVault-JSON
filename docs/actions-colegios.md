# Pruebas de Colegio Cerca

En la pestaña Actions, selecciona una ejecución de la rama de entrega y abre el trabajo para leer sus resultados. Los workflows de Jhair comprueban la sintaxis de JavaScript, el catálogo de diez colegios, los filtros, las fichas de detalle, la estructura del HTML y la respuesta HTTP de la web. Las pruebas de fichas revisan también teléfonos, ubicaciones en Maps y fuentes. Para repetirlas en tu laptop, usa el comando Node.js del [borrador de entrega](../README.md).
